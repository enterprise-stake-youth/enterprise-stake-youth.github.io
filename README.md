# Stake Youth Permissions — public pages

The pages families, leaders, and approvers open (permission sign-up, signing, event plan, approval).
All data, emails, and PDFs live in the Enterprise Utah Stake's Google account (Apps Script); this site
only shows the pages and talks to that app. It contains no member data.

`index.html` is generated — don't edit it by hand. Source and build steps are in the app's project
folder (`tools/build_site.py`, README → "Public website").
